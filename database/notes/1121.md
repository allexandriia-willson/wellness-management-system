:: New Concept: More Data Types
1. Service Duration = INTEGER
because we do math with it based on the start time.
Eg. Start Time: 2:00 PM
    Duration: 90 Minutes
The system can calculate:
    End Time: 3:30 PM
That's why: service_duration INTEGER
2. Service Price ≠ TEXT
once again, because we do math with it since we're dealing with money.
Eg. Guest Price: $120.00
    Discount:    $20.00
    --------------------
    Total:       $100.00
or
    - Subtotal
    - Tax
    - Tip
    - Provider Commission
    All of which require calculations.
3. REAL
because we're dealing with money & decimals (in most cases)
Eg. 100
    100.00
    99.99
    75.59
INTEGER can only store: 100
                        99
                        75

Business Analysis
: Why a SERVICES table? Services aren't appointments.
Eg. 60-Min Deep Tissue Massage - exists independently.
Whether: 0 people book it
         10 people book it
         10,000 people book it ... the service still exists.
So SERVICES & APPOINTMENT are separate tables.

:: New Concept: Relationships
: Clients       Employees        Services
     ↓              ↓               ↓
Appointments   Appointments    Appointments
We're moving from Storing Information to Connecting Information

:: New Concept: Foreign Keys
we use: client_id INTEGER PRIMARY KEY AUTOINCREMENT
because: every client gets a unique ID

Now: Clients
     Client ID      Name
     ----------------------------
     1              Alexandria

     3              Michael
Suppose Alexandria books a Sports Massage.
How to connect = Alexandria
to = Appointment #500

We need to save = client_id = 1 (the value points to the client) This is a foreign key




Business Languae to Database Language
Business            Database
Receiving Client    client_id
Service Provider    employee_id
Service Type        service_id

- client_id INTERGER NOT NULL: doesn't store Alexandria Wilson. it stores: 1, which points to Alexandria in the Clients table.
- employee_id INTEGER NOT NULL: instead of Jessica M, it stores 14, pointing to Jessica's Employee records.
- service_id INTEGER NOT NULL: instead of 90-Min Lymphatic Massage, it stores 9, which points to the services in the Services table.
