::: Service Duration vs End Time
When a client books: 60-Min Sports Massage
The systems knows: 60 minutes

because the duration belongs to the service itself rather than the appointment.

eg. Services Table
    Service ID: 1
    Service Name: 60-Min Sports Massage
    Duration: 60

    Service ID: 2
    Service Name: 90-Min Sports Massage
    Duraton: 90
Then the appointment stores:
    Service Type = 60-Min Sports Massage
    Start Time = 2:00 PM
The system calculates:
    End Time = 3:00 PM
No need to save it separately.

So, duration doesn't belong to the appointment. It belongs to: Services. Which means we need another table:
SERVICES
- Service ID
- Service Name
- Service Duration
- Service Price
- Room Number
- Service Category
eg. 60-Min Total Body Stretch
    90-Min Lymphatic Massage
    60-Min Brightening Facial
    120-Min Deep Tissue Massage
